# So trittst du deinem QANGA Server bei

Deinen QANGA Server findest du im Spiel über die **Serverliste**. Nach dem Start meldet sich dein Server selbstständig bei Steam an und erscheint dort mit dem Namen, der in der **Verwaltung** hinterlegt ist.

## Verbindungsdaten finden

:::: danger Wichtig
Du suchst deinen Server in der Serverliste über seinen **Namen**. Welchen Namen dein Server verwendet, siehst du in der **Verwaltung** deines Servers.
::::

## Server beitreten

1. <b>QANGA starten</b><br>
   Starte QANGA auf deinem PC und warte, bis das Hauptmenü geladen ist.

2. <b>Serverliste öffnen</b><br>
   Öffne im Hauptmenü den Online-Modus. Du siehst nun die Liste der verfügbaren Server.

3. <b>Server suchen</b><br>
   Suche in der Liste nach dem Namen deines Servers. Bei vielen Einträgen hilft es, den Namen in die Suche einzugeben.

4. <b>Beitreten</b><br>
   Wähle deinen Server aus und bestätige den Beitritt.

5. <b>Passwort eingeben</b><br>
   Ist für deinen Server ein Passwort gesetzt, gib es jetzt ein und bestätige.

## Musst du Ports freigeben?

:::: info Hinweis
Nein. Auf deinem gemieteten Server ist das nicht nötig – die Ports sind bereits eingerichtet und stehen in der **Verwaltung**.

Dein Server nutzt dabei zwei Ports:

| Port | Verwendung |
|------|------------|
| **Game Port** | Über diesen Port läuft die Spielverbindung. |
| **Query Port** | Über diesen Port meldet sich der Server bei Steam an, damit er in der Serverliste erscheint. |

Beide Ports werden dir automatisch zugewiesen.
::::

## Server erscheint nicht in der Liste

Taucht dein Server nach dem Start nicht sofort auf, hilft in der Regel etwas Geduld — die Anmeldung bei Steam dauert nach jedem Start einen Moment. Prüfe zusätzlich:

- Läuft der Server? In der **Verwaltung** muss der Status auf **Online** stehen.
- Hast du nach einer Änderung in der Verwaltung neu gestartet? Die Startparameter werden erst mit einem Neustart übernommen.
- Suchst du nach dem exakten Namen? Die Suche in der Serverliste reagiert auf Tippfehler.
- Aktualisiere die Serverliste im Spiel, statt nur zu warten.

:::: warning Achtung
Läuft der Server, erscheint aber dauerhaft nicht in der Liste, schau in die **Konsole** deines Servers. Fehler beim Start oder ein noch laufendes Update sind die häufigste Ursache.
::::

:::: info Hinweis
Dein Spielfortschritt auf diesem Server liegt auf dem Server selbst. Eure gemeinsame Welt bleibt damit erhalten, auch wenn gerade niemand online ist.
::::
