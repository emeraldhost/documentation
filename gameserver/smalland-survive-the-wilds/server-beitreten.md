# So trittst du deinem Smalland Survive the Wilds Server bei

Smalland Survive the Wilds hat **keine Direktverbindung über die IP-Adresse**. Du findest deinen Server ausschließlich über den Serverbrowser im Spiel, indem du dort nach dem **Namen deines Servers** suchst.

:::: danger Wichtig
IP-Adresse und Port brauchst du zum Beitreten **nicht**. Es gibt im Spiel kein Eingabefeld dafür. Entscheidend ist allein der **Servername**, den du in der Verwaltung deines Servers festgelegt hast.
::::

## Server suchen und beitreten

1. <b>Smalland starten</b><br>
   Starte das Spiel und warte, bis das Hauptmenü geladen ist.

2. <b>Play wählen</b><br>
   Klicke im Hauptmenü auf **Play**.

3. <b>Charakter wählen</b><br>
   Wähle einen vorhandenen Charakter aus oder erstelle einen neuen.

   :::: info Hinweis
   Dein Charakter liegt auf deinem eigenen PC, nicht auf dem Server. Du kannst denselben Charakter deshalb auf jedem Server verwenden.
   ::::

4. <b>Serverbrowser öffnen</b><br>
   Wechsle auf dem folgenden Bildschirm mit den Welten oben auf **Join**.

5. <b>Nach dem Servernamen suchen</b><br>
   Gib im Suchfeld den **Namen deines Servers** ein.

   :::: warning Achtung
   Gesucht wird nach dem **Servernamen**, nicht nach dem Weltnamen. Beide Werte sind unabhängig voneinander – der Weltname bestimmt nur, welcher Spielstand geladen wird.
   ::::

6. <b>Filter prüfen</b><br>
   Achte darauf, dass die Filter im Serverbrowser zu deinem Server passen, zum Beispiel **Public** oder **Crossplay**. Passt ein Filter nicht, wird dein Server nicht angezeigt, obwohl er läuft.

7. <b>Beitreten</b><br>
   Klicke deinen Server in der Liste an und bestätige mit **Join** – alternativ genügt ein Doppelklick auf den Eintrag.

8. <b>Passwort eingeben</b><br>
   Hast du ein Serverpasswort gesetzt, wirst du beim Beitreten danach gefragt. Trage es exakt so ein, wie es in der Verwaltung hinterlegt ist.

:::: tip Server als Favorit speichern
Über **Add to Favorites** legst du deinen Server im Serverbrowser als Favorit ab. Danach findest du ihn beim nächsten Mal ohne erneute Suche wieder.
::::

## Server wird nicht gefunden

:::: warning Achtung
Findest du deinen Server nicht, geh diese Punkte der Reihe nach durch:

- Läuft der Server? Prüfe den Status in der **Verwaltung**.
- Ist der Server gerade erst gestartet? Es dauert einen Moment, bis er im Browser erscheint.
- Suchst du wirklich nach dem **Servernamen** und nicht nach dem Weltnamen?
- Passen die Filter im Serverbrowser, etwa **Public**, **Crossplay** oder **Favorites**?
- Ist die Einstellung für einen privaten Server aktiv? Dann erscheint dein Server **gar nicht** in der Liste.
::::

:::: danger Privater Server
Aktivierst du in der Verwaltung die Option für einen privaten Server, wird dein Server im Serverbrowser komplett ausgeblendet. Da Smalland keine Direktverbindung über die IP-Adresse kennt, können deine Mitspieler ihn dann nicht mehr auswählen. Möchtest du deinen Server nur vor Fremden schützen, setze stattdessen ein **Serverpasswort**.
::::

## Welche Ports nutzt Smalland Survive the Wilds?

:::: info Hinweis
Ein Smalland-Server belegt lediglich einen **Game Port** (UDP). Einen **Query Port** oder einen RCON-Port gibt es nicht. Welcher Game Port für deinen Server gilt, siehst du in der **Verwaltung**.

Im Spiel trägst du diesen Port nirgends ein: Der Beitritt läuft ausschließlich über den Serverbrowser, der die Verbindung im Hintergrund selbst herstellt.
::::
