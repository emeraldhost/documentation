# Terraria tShock

## Was ist Terraria tShock?

tShock ist eine serverseitige Erweiterung für dedizierte Terraria-Server. Sie ersetzt das schlichte Serverprogramm von Re-Logic durch eine deutlich mächtigere Variante, die auf der Terraria Server API aufsetzt und dem Betreiber Werkzeuge für Verwaltung, Moderation und Erweiterung an die Hand gibt.

Das Herzstück von tShock ist ein Benutzer- und Gruppensystem: Spieler können sich mit Benutzername und Passwort an einem Account anmelden, der einer Gruppe wie `default`, `vip`, `admin` oder `owner` zugeordnet ist. Über Berechtigungen legst du fest, welche Gruppe welche Befehle nutzen darf. Dazu kommen ein umfangreiches Bannsystem mit Ticketnummern und zeitlich begrenzten Banns, Chat- und Moderationsbefehle sowie automatische Weltsicherungen in festen Intervallen.

Erweitert wird ein tShock-Server über Plugins – kleine Programmbausteine, die ausschließlich auf dem Server liegen und dort neue Befehle, Regeln oder Spielmechaniken ergänzen. Ein zusätzlicher Speicher für Charakterdaten (Server Side Characters) sorgt auf Wunsch dafür, dass Inventar und Fortschritt der Spieler direkt auf dem Server liegen und nicht mehr lokal manipuliert werden können.

Für die Spieler ändert sich nichts: Sie verbinden sich mit dem ganz normalen, unveränderten Terraria-Client über **Join via IP** mit deinem Server. tShock ist damit kein Modloader – Mods im Sinne von `.tmod`-Dateien lassen sich nicht laden, dafür gibt es den separaten Servertyp Terraria tModLoader.
