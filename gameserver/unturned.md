# Unturned

## Was ist Unturned?

Unturned ist ein kostenloses Survival-Sandbox-Spiel von Smartly Dressed Games, dem Studio von Nelson Sexton. Die Spieler schlagen sich in einer von Zombies überrannten Welt durch, sammeln Ausrüstung, sichern sich Nahrung und Wasser und bauen sich Schritt für Schritt eine eigene Basis auf. Die bewusst klotzige Low-Poly-Optik täuscht dabei über einen erstaunlich tiefen Survival-Unterbau hinweg.

Im Mittelpunkt stehen Looten, Crafting, Basenbau und Fahrzeuge. Aus gefundenen Rohstoffen entstehen Waffen, Werkzeuge, Kleidung und Befestigungen, Fahrzeuge werden repariert und betankt, und Felder lassen sich für den Nachschub bewirtschaften. Je nach Servereinstellung reicht das Spiel von entspanntem Aufbau bis zu hartem PvP.

Unturned bringt eine Reihe offizieller Karten mit, darunter Prince Edward Island, Washington, Yukon und Russia. Dazu kommt eine sehr aktive Steam-Workshop-Anbindung: Kuratierte Karten wie Elver, Carpat, Hawaii oder Greece sowie unzählige Mods mit neuen Waffen, Fahrzeugen und Spielmechaniken lassen sich direkt in einen Server einbinden.

Auf einem eigenen Server bestimmst du, wie gespielt wird. Über Konfigurationsdateien und Konsolenbefehle legst du Karte, Schwierigkeitsgrad, Adminrechte und Zugangsregeln fest, und über den Workshop stattest du deinen Server mit genau den Karten und Mods aus, die deine Gruppe spielen möchte. Mods, die auf dem Server hinterlegt sind, laden Spieler beim Verbinden automatisch herunter.

Unturned ist besonders bei Spielern beliebt, die gemeinsam mit Freunden einen unkomplizierten Einstieg in das Survival-Genre suchen und ihren Server frei anpassen möchten. Das Spiel ist kostenlos auf PC über Steam verfügbar.
