# Quake Live

## Was ist Quake Live?

Quake Live ist ein Arena-Shooter von id Software und eine überarbeitete Fassung von Quake III Arena. Ursprünglich startete das Spiel als kostenloses Angebot, das über ein Browser-Plugin gespielt wurde. Am 17. September 2014 erschien es als eigenständiger Titel auf Steam, seit dem 27. Oktober 2015 ist es kostenpflichtig und die früheren Abo-Modelle wurden eingestellt.

Im Mittelpunkt steht das klassische Arena-Gameplay: hohes Tempo, Bewegungstechniken wie Strafe-Jumps, Kontrolle über Rüstungen und Waffen sowie kurze, intensive Duelle. Es gibt keine Kampagne und keine Spielwelt, die gespeichert wird — jede Runde beginnt auf einer Map neu und endet mit dem Erreichen des Frag-, Punkte- oder Zeitlimits.

Ein Quake Live Server ist von Haus aus für mehrere Spielmodi gleichzeitig ausgelegt. Unterstützt werden unter anderem Free For All, Duel, Race, Team Deathmatch, Clan Arena, Capture the Flag, One Flag CTF, Harvester, Freeze Tag, Domination, Attack & Defend und Red Rover. Über sogenannte Factories lassen sich daraus eigene Regelsätze bauen, zum Beispiel eine InstaGib-Variante — die Einstellungen liegen dabei in einer JSON-Datei und nicht in der Serverkonfiguration.

Welche Maps auf dem Server laufen, steuerst du über einen Map-Pool. Zusätzliche Inhalte wie Custom-Maps oder fremde Factories kommen ausschließlich aus dem Steam Workshop: Du trägst die Item-IDs auf dem Server ein, der Server lädt sie beim Start herunter und deine Mitspieler bekommen sie automatisch. Adminrechte und Banns verwaltet Quake Live über eine einfache Textdatei mit SteamID64-Einträgen.

Quake Live ist besonders bei Spielern beliebt, die klassisches Arena-Gameplay ohne Matchmaking und ohne Fortschrittssystem suchen — und die ihren Server für feste Runden, Duelle oder eine eigene Community frei konfigurieren wollen. Das Spiel ist auf dem PC über Steam verfügbar.
