# So änderst du das Wetter auf einem The Bus Server

Du kannst das Wetter auf deinem Server per **Befehl** im Ingame-Chat ändern.

1. <b>Ingame-Chat öffnen</b><br>
   [Verbinde dich mit deinem Server](server-beitreten.md) und öffne den Ingame-Chat. Du benötigst Owner- oder Admin-Rechte – wie du einen Admin festlegst, erfährst du unter [Admin hinzufügen](admin-hinzufuegen.md).

2. <b>Befehl eingeben</b><br>
   Gib folgenden Befehl ein und ersetze `<wetter>` durch das gewünschte Wetter:

   ```
   /weather <wetter>
   ```

:::: tip Tipp
Welche Werte `/weather` genau erwartet, ist nicht offiziell dokumentiert. Mit `/commands` lässt du dir alle verfügbaren Befehle anzeigen.
::::

:::: info Hinweis
Befehle funktionieren nur im Ingame-Chat. Die Konsole in der Verwaltung zeigt nur das Server-Log an und nimmt keine Befehle entgegen.
::::

Wie du Tageszeit und Datum änderst, erfährst du unter [Tageszeit ändern](tageszeit-aendern.md).
