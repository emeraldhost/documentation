# s&box

## Was ist s&box?

s&box ist eine Spieleplattform von Facepunch Studios, dem Studio hinter Garry's Mod und Rust. Sie gilt als geistiger Nachfolger von Garry's Mod: Statt eines einzelnen Spiels bekommst du eine Umgebung, in der Spielmodi, Maps und Werkzeuge von der Community erstellt und direkt im Spiel geladen werden.

Technisch setzt s&box auf die Source 2 Engine. Spielinhalte werden in C# geschrieben und laufen in einer abgesicherten Umgebung, sodass ein Server seinen Spielern nicht nur Assets, sondern auch den Spielcode direkt übertragen kann. Für die Spieler bedeutet das: Es muss nichts vorab installiert werden, alles Nötige kommt beim Beitritt vom Server beziehungsweise aus der Cloud.

Alle Inhalte liegen als sogenannte Packages auf der Plattform sbox.game. Ein Package kann ein Spielmodus, eine Map, ein Modell oder eine Bibliothek sein und wird über einen Ident nach dem Muster `organisation.package` angesprochen — zum Beispiel `facepunch.sandbox` für den offiziellen Sandbox-Modus. Auf einem Server legst du damit fest, welcher Spielmodus und welche Map laufen sollen.

Der offizielle Sandbox-Modus knüpft direkt an Garry's Mod an: Objekte spawnen, mit Physik experimentieren, Konstruktionen bauen und gemeinsam mit anderen herumprobieren. Daneben entstehen laufend Community-Spielmodi von klassischen Shooter- und Rollenspiel-Modi bis zu Party- und Rätselspielen.

s&box ist am 28. April 2026 erschienen und für PC über Steam verfügbar.
