# BATTALION Legacy

## Was ist BATTALION Legacy?

BATTALION Legacy ist ein kostenloser Mehrspieler-Shooter im Setting des Zweiten Weltkriegs von Bulkhead. Das Spiel setzt konsequent auf schnelle, wettkampforientierte Gefechte zwischen zwei Teams: Es gibt keinen Einzelspieler-Modus und keine offene Welt, sondern ausschließlich rundenbasiertes PvP auf kompakten Karten.

Im Mittelpunkt steht der Modus **Wartide**, in dem beide Teams abwechselnd angreifen und verteidigen und sich zwischen den Runden mit ihren verdienten Mitteln neu ausrüsten. Der Fokus liegt auf präzisem Zielen, Positionierung und Absprache im Team — Fähigkeiten oder Fortschrittsboni, die einzelne Spieler stärker machen, gibt es nicht.

Ein eigener Server ist vor allem dann interessant, wenn du mit deinem Team unter euch spielen, eigene Matches austragen oder eine feste Anlaufstelle für deine Community bereitstellen möchtest. Deinen Server finden deine Mitspieler über den Serverbrowser im Spiel.

Serverseitig ist BATTALION Legacy sehr schlank aufgebaut. Der Server wird über seine Startparameter konfiguriert — im Wesentlichen über den Servernamen, die Ports und das Admin-Passwort. Es gibt keinen Weltspeicherstand, keinen Steam Workshop und damit auch keine Mods. Ab Werk startet dein Server im Modus **Wartide**; die Karte lässt sich im laufenden Betrieb über die Adminkonsole wechseln.

Die Serverdateien von BATTALION Legacy werden von den Entwicklern nicht mehr aktualisiert — der letzte Stand stammt aus dem August 2022. Dein Server läuft damit auf einer stabilen, unveränderlichen Version.

BATTALION Legacy ist besonders bei Spielern beliebt, die einen klassischen, taktischen Wettkampf-Shooter ohne Ablenkung suchen. Das Spiel ist auf dem PC über Steam kostenlos verfügbar.
