# So trittst du deinem RuneScape: Dragonwilds Server bei

Du kannst deinem Server auf zwei Wegen beitreten: über die Suche nach dem **Welt-Namen** im Welten-Bildschirm oder direkt über den Tab **Direkt** mit der **IP-Adresse** deines Servers.

:::: info Hinweis
Den Welt-Namen findest du in den **Einstellungen** deines Servers in der Verwaltung. Die IP-Adresse und den Game Port findest du in der Verwaltung unter der **Übersicht**.
::::

## Über den Welt-Namen

1. <b>Spiel starten</b><br>
   Starte RuneScape: Dragonwilds.

2. <b>Welten öffnen</b><br>
   Öffne den **Welten**-Bildschirm und wähle den Tab **Public**.

3. <b>Server suchen</b><br>
   Öffne die **Suche** und gib den exakten Welt-Namen deines Servers ein.

   :::: warning Achtung
   Der Welt-Name ist **groß-/kleinschreibungsempfindlich**. Er muss exakt übereinstimmen.
   ::::

4. <b>Server beitreten</b><br>
   Warte einige Sekunden, bis dein Server in der Liste erscheint, und tritt bei.

## Über den Direkt-Tab

1. <b>Spiel starten</b><br>
   Starte RuneScape: Dragonwilds und öffne den **Welten**-Bildschirm.

2. <b>Direkt-Tab öffnen</b><br>
   Wähle in der oberen Leiste den Tab **Direkt**.

3. <b>Verbindungsdaten eingeben</b><br>
   Trage die IP-Adresse und den Game Port deines Servers in die jeweiligen Felder ein. Hat dein Server ein [Server-Passwort](server-passwort-setzen.md), gib es im Feld darunter an.

   :::: tip Beispiel
   ```
   IP-Adresse: 123.45.67.89
   Port: 7777
   ```
   ::::

4. <b>Charakter wählen und verbinden</b><br>
   Wähle deinen Charakter aus oder erstelle einen neuen und klicke auf **Spielen**, um dich mit dem Server zu verbinden.

:::: tip Fehlerbehebung
Falls dein Server über den Welt-Namen nicht gefunden wird:
- Stelle sicher, dass die [Owner ID](owner-id-setzen.md) hinterlegt ist
- Stelle sicher, dass der Welt-Name exakt übereinstimmt
- Prüfe, ob dein Spiel und der Server auf derselben Version sind
- Warte einige Minuten nach dem Serverstart, bevor du suchst
- Verbinde dich alternativ über den **Direkt**-Tab mit der IP-Adresse
::::
