# Operation Harsh Doorstop

## Was ist Operation Harsh Doorstop?

Operation Harsh Doorstop ist ein taktischer Multiplayer-Shooter von Drakeling Labs, der kostenlos über Steam verfügbar ist. Das Spiel setzt auf bodenständige Infanteriegefechte in großen, offenen Karten und richtet sich an Spieler, die teambasiertes, taktisches Vorgehen dem schnellen Arcade-Shooter vorziehen.

Gespielt wird in rundenbasierten Modi, in denen zwei Fraktionen um Kontrollpunkte kämpfen. Neben reinem PvP lassen sich Runden auch mit KI-Bots auffüllen, sodass du selbst auf einem kleinen Server oder mit wenigen Freunden volle Gefechte erleben kannst. Nach jeder Runde startet der Server eine neue Partie – einen dauerhaft gespeicherten Weltzustand gibt es nicht.

Das Herzstück des Spiels ist die Modbarkeit: Karten, Fraktionen, Waffen und ganze Spielmodi stammen aus dem Steam Workshop und werden von der Community erstellt. Auf einem eigenen Server bestimmst du, welche Mods laufen, welche Karten rotieren und welche Fraktionen gegeneinander antreten.

Auf deinem eigenen Server verwaltest du außerdem Admins und Bans über Konfigurationsdateien und steuerst das laufende Spiel per Ingame-Konsole oder RCON – vom Kartenwechsel bis zum Kick einzelner Spieler.

Operation Harsh Doorstop ist auf dem PC über Steam erhältlich und ist kostenlos spielbar.
