# So trittst du deinem Myth of Empires Server bei

Deinem Myth of Empires Server trittst du über den Serverbrowser im Spiel bei. Dort suchst du deinen Server anhand seines **Namens** und verbindest dich mit einem Klick.

:::: info Hinweis
Über Steam – also den Steam-Serverbrowser oder die Steam-Favoriten – lässt sich ein Myth of Empires Server **nicht** betreten. Der Weg auf deinen Server führt über den Serverbrowser im Spiel, in dem du deinen Server anhand seines Namens suchst. Gib deinem Server deshalb einen eindeutigen Namen, den du in der Liste schnell wiederfindest.
::::

## Server im Spiel suchen

1. <b>Myth of Empires starten</b><br>
   Starte das Spiel und warte, bis das Hauptmenü geladen ist.

2. <b>Eigene Server öffnen</b><br>
   Wähle im Hauptmenü **Custom Server** (Eigener Server).

3. <b>Reiter wählen</b><br>
   Wechsle auf den Reiter **Single Server**. Dort werden einzelne Server aufgelistet.

   :::: info Hinweis
   Gehört dein Server zu einem Verbund aus mehreren Karten, findest du ihn stattdessen unter dem Reiter **World**.
   ::::

4. <b>Server suchen</b><br>
   Gib den Namen deines Servers in das Suchfeld ein. Die Liste wird auf passende Treffer eingegrenzt.

   :::: tip Tipp
   Den Namen deines Servers findest du in der **Verwaltung**. Suche notfalls nur nach einem markanten Teil des Namens.
   ::::

5. <b>Verbinden</b><br>
   Klicke deinen Server an und bestätige den Beitritt.

6. <b>Passwort eingeben</b><br>
   Hast du für deinen Server ein Passwort gesetzt, wirst du beim Beitreten danach gefragt. Trage es ein und bestätige.

7. <b>Charakter erstellen</b><br>
   Beim ersten Beitritt legst du deinen Charakter an. Danach wird dein Fortschritt auf dem Server gespeichert.

## Server erscheint nicht in der Liste

1. <b>Server prüfen</b><br>
   Sieh in der **Verwaltung** nach, ob dein Server tatsächlich läuft. Ein frisch gestarteter Server braucht einen Moment, bis er sich in der offiziellen Serverliste angemeldet hat.

2. <b>Liste aktualisieren</b><br>
   Aktualisiere die Serverliste im Spiel und suche erneut.

3. <b>Namen prüfen</b><br>
   Vergleiche die Schreibweise: Suchst du nach einem Namen mit Tippfehler, bleibt die Liste leer. Suche im Zweifel nur nach einem kurzen, eindeutigen Teil des Namens.

4. <b>Reiter prüfen</b><br>
   Ein einzelner Server erscheint unter **Single Server**. Gehört dein Server zu einem Verbund aus mehreren Karten, suchst du ihn stattdessen im Reiter für Weltenverbunde (**World**).

:::: info Welche Ports nutzt Myth of Empires?
Ein Myth of Empires Server belegt mehrere Ports. Die konkreten Werte werden deinem Server in der **Verwaltung** zugewiesen – verlass dich immer auf die Zahlen, die dort stehen.

| Port | Verwendung |
|------|-----------|
| **Game Port** | Der eigentliche Spielverkehr – darüber läuft deine Verbindung zum Server |
| **Query Port** | Darüber meldet sich dein Server in der Serverliste und wird abgefragt |

Damit dein Server gefunden wird und Spieler beitreten können, müssen **beide** Ports erreichbar sein. Fehlt der Query Port, taucht dein Server gar nicht erst in der Liste auf.
::::
