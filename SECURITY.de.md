# Sicherheitsrichtlinie

*Read this in [English](./SECURITY.md).*

In diesem Repository liegt öffentliche Dokumentation. Es gibt hier keinen
Anwendungscode und keine Kundendatenbank, eine klassische Schwachstellenmeldung
passt also nicht. Zwei Dinge solltest Du trotzdem melden, und zwar vertraulich.

## Was Du vertraulich melden solltest

- **Eine Anleitung zeigt etwas, das nicht öffentlich sein darf**, zum Beispiel
  ein Token, einen Lizenzschlüssel, ein Passwort, die IP-Adresse einer anderen
  Kundin oder eines anderen Kunden oder eine echte E-Mail-Adresse, im Text oder
  auf einem Screenshot.
- **Eine Anleitung erklärt etwas Gefährliches**, zum Beispiel einen Befehl, der
  ohne Warnung Daten löscht, eine Firewall abschaltet oder einen Dienst offen
  ins Internet stellt.

## Wie Du meldest

Bitte öffne für diese beiden Fälle kein Issue und keinen Pull Request. Beides
kopiert das Problem in die öffentliche Historie des Repositories.

Schreib uns stattdessen über die
[Support-Seite](https://emeraldhost.de/de/support) und nenne die Anleitung, am
besten mit ihrem Pfad, zum Beispiel
`tutorials/gameserver/minecraft/change-version`. Wir sehen uns das so schnell
wie möglich an, korrigieren die Anleitung oder nehmen sie offline und sagen Dir,
was wir geändert haben.

## Alles andere

Ein kaputter Link, ein falscher Schritt, ein veralteter Screenshot oder eine
fehlende Übersetzung ist normales Feedback und gehört in ein
[Issue](https://github.com/emeraldhost/documentation/issues) oder in einen Pull
Request. [`CONTRIBUTING.de.md`](./CONTRIBUTING.de.md) erklärt, wie das geht.
