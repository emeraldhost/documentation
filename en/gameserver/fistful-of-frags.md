# Fistful of Frags

## What is Fistful of Frags?

Fistful of Frags is a multiplayer shooter set in the Wild West, built on the Source SDK 2013. Instead of modern assault rifles, players fight with revolvers, lever-action rifles, shotguns, throwing knives and dynamite — and since many weapons can be dual wielded, the result is classic saloon shootouts with slow reloads and high risk.

There is no campaign — apart from a few practice challenges to get you started, Fistful of Frags takes place on servers. The server setting `fof_sv_currentmode` decides which game mode runs — among them Shootout (free for all), Teamplay, Break Bad, Elimination and Versus. Up to four teams are possible, and if you cannot fill a full round, the built-in bots top the server up.

The game ships with a large selection of official maps whose prefix hints at the matching mode: `fof_` stands for Shootout, `tp_` for Teamplay. On top of that there are further map series with the prefixes `vs_`, `gt_`, `cm_` and `fofhr_`. Many classics also come as `_12` variants for smaller rounds, along with matching mapcycle files for 12-slot and 32-slot servers.

On the server side Fistful of Frags is a classic Source game: the configuration runs through the `server.cfg`, the map rotation through mapcycle files, extensions run through Metamod:Source and SourceMod, and custom maps can be added as `.bsp` files. The game does not ship its own admin system — in-game admin rights are only available through SourceMod, everything else runs through the server console. In return Fistful of Frags has a built-in votekick system that lets players deal with troublemakers even when no admin is present.

Fistful of Frags is particularly popular among players looking for fast, chaotic duels with a Western flair, where weapon handling matters more than loadout upgrades. The game is available on PC via Steam free of charge.
