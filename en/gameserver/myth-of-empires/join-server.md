# How to Join Your Myth of Empires Server

You join your Myth of Empires server through the in-game server browser. There you search for your server by its **name** and connect with a single click.

:::: info Note
A Myth of Empires server can **not** be joined through Steam – neither through the Steam server browser nor through the Steam favorites. The way onto your server is the in-game server browser, where you search for your server by its name. Give your server a distinctive name so you can find it quickly in the list.
::::

## Find your server in the game

1. <b>Start Myth of Empires</b><br>
   Launch the game and wait until the main menu has loaded.

2. <b>Open the custom servers</b><br>
   Select **Custom Server** in the main menu.

3. <b>Choose the tab</b><br>
   Switch to the **Single Server** tab. Individual servers are listed there.

   :::: info Note
   If your server is part of a cluster of several maps, you find it under the **World** tab instead.
   ::::

4. <b>Search for your server</b><br>
   Type the name of your server into the search field. The list is filtered down to matching results.

   :::: tip Tip
   You can find the name of your server in the **dashboard**. If needed, search for a distinctive part of the name only.
   ::::

5. <b>Connect</b><br>
   Click your server and confirm to join.

6. <b>Enter the password</b><br>
   If you set a password for your server, you are prompted for it when joining. Enter it and confirm.

7. <b>Create your character</b><br>
   The first time you join you create your character. From then on your progress is stored on the server.

## Server does not appear in the list

1. <b>Check the server</b><br>
   Check in the **dashboard** whether your server is actually running. A freshly started server needs a moment before it has registered with the official server list.

2. <b>Refresh the list</b><br>
   Refresh the server list in the game and search again.

3. <b>Check the name</b><br>
   Compare the spelling: if you search for a name with a typo, the list stays empty. When in doubt, search for a short, distinctive part of the name only.

4. <b>Check the tab</b><br>
   A single server appears under **Single Server**. If your server is part of a cluster of several maps, look for it in the tab for connected worlds (**World**) instead.

:::: info Which ports does Myth of Empires use?
A Myth of Empires server occupies several ports. The actual values are assigned to your server in the **dashboard** – always rely on the numbers shown there.

| Port | Purpose |
|------|---------|
| **Game Port** | The actual game traffic – your connection to the server runs through it |
| **Query Port** | Your server announces itself in the server list and is queried through it |

For your server to be found and for players to be able to join, **both** ports have to be reachable. Without the Query Port your server does not show up in the list at all.
::::

:::: tip Tip
If you want to use admin commands on your server, add yourself as an admin first: [Add Admin](add-admin.md).
::::
