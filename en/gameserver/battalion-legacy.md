# BATTALION Legacy

## What is BATTALION Legacy?

BATTALION Legacy is a free-to-play multiplayer shooter set in World War II, developed by Bulkhead. The game focuses entirely on fast, competitive matches between two teams: there is no single-player mode and no open world, only round-based PvP on compact maps.

The centrepiece is the **Wartide** mode, in which both teams take turns attacking and defending and re-equip themselves between rounds with the resources they earned. The focus is on precise aiming, positioning and team communication — there are no abilities or progression bonuses that make individual players stronger.

Your own server is particularly interesting if you want to play among your own team, host your own matches or provide a permanent home for your community. Your players find your server through the in-game server browser.

On the server side, BATTALION Legacy is very lightweight. The server is configured through its startup parameters — essentially the server name, the ports and the admin password. There is no world save, no Steam Workshop and therefore no mods. Out of the box your server starts in the **Wartide** mode; the map can be switched at runtime through the admin console.

The BATTALION Legacy server files are no longer updated by the developers — the latest build dates back to August 2022. Your server therefore runs on a stable, unchanging version.

BATTALION Legacy is especially popular with players looking for a classic, tactical competitive shooter without distractions. The game is available for free on PC via Steam.
