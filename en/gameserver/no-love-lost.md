# No Love Lost

## What is No Love Lost?

No Love Lost is a free-to-play PvPvE extraction game by Ratloop Games Canada. Up to ten players drop onto the planet Drosera, harvest a resource called Nectar and face both the hostile wildlife and the other crews while doing so.

The appeal of the game lies in the risk: a session lasts about 15 minutes, and your Nectar is only yours once you make it onto the extraction ship in time. This creates a constant trade-off between harvesting a little more and retreating safely — especially when other crews nearby are after the same thing. Between successful extractions you build up lasting perks for your character.

The game is played in individual sessions that are hosted on a server. Your own server is particularly interesting if you want to stay among your own group and decide when the rounds happen, instead of relying on public sessions.

On the server side, No Love Lost is deliberately lightweight: the server is configured exclusively through its startup parameters — essentially the server name plus the Game Port and the Query Port. There is no configuration file you would have to edit in the file manager.

No Love Lost is especially popular with players looking for short, tense extraction rounds with friends. The game was released on 12 March 2024 and is available for free on PC via Steam.
