# How to Change the Ticket Chance on a The Bus Server

The ticket chance determines how likely passengers on your server are to buy a ticket. You change it with a command in the in-game chat. The command was introduced with Update 3.2.

:::: info Note
This command requires Owner or Admin permissions. To learn how to add an admin, see [Add Admin](add-admin.md). On our servers, the console in the dashboard only shows the server output and does not accept commands.
::::

## How to Set the Ticket Chance

1. <b>Open the in-game chat</b><br>
   [Join your server](join-server.md) and open the in-game chat.

2. <b>Set the ticket chance</b><br>
   Enter the following command and replace `<value>` with a value from `0` to `100`:

   ```
   /tickets <value>
   ```

   For example:

   ```
   /tickets 50
   ```

:::: tip Tip
The command is `/tickets`, not `/ticketchance`. Use `/commands` to show all available commands.
::::
