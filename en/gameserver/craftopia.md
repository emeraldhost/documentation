# Craftopia

## What is Craftopia?

Craftopia is an open world survival crafting game by the Japanese developer Pocketpair, available in Early Access since 2020. The game deliberately mixes a wide range of genres: gathering and survival, farming and animal breeding, hack and slash combat, dungeons, boss fights and automation with conveyor belts and machines.

You start with nothing but your hands, chop down trees, build tools and set up your first base. Later on you unlock ways to get around such as gliders and a grappling hook, capture and breed monsters, automate your production and gear up for the bosses of the island. A skill tree and steadily better equipment keep your character growing throughout the entire game.

The so called Seamless update in June 2023 rebuilt the game world from the ground up: instead of separate islands that had to be loaded individually, there is now one connected world without loading screens in between. The save format and the dedicated server were reworked for this as well.

Craftopia can be played solo, but it really shines in co-op on a shared server. A dedicated server is set to seven players by default and can be expanded to up to 127 slots. The game is available on PC via Steam.
