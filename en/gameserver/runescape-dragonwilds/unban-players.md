# How to Unban Players on Your RuneScape: Dragonwilds Server

You can unban banned players via the in-game **Server Management** menu. However, this is only possible as the **Owner** of your server, not as an admin.

## Owner and admin

There are two roles on your server with different permissions:

| Role | Requirement | Ban (online) | Ban (offline) | Unban |
|------|-------------|--------------|---------------|-------|
| Owner | Player ID matches the [Owner ID](set-owner-id.md) in the dashboard | Yes | Yes | Yes |
| Admin | Entered the [admin password](set-admin-password.md) in Server Management | Yes (regular players only) | No | No |

## Unban a player

1. <b>Join as owner</b><br>
   [Join your server](join-server.md) with the account whose Player ID is set as the Owner ID.

2. <b>Open the pause menu</b><br>
   Press the pause button to open the menu.

3. <b>Open Server Management</b><br>
   Navigate to **Settings** and select **Server Management**. Enter the admin password if prompted.

4. <b>Unban the player</b><br>
   Select the player in the list of banned players and choose the option to unban them. The player can then join your server again.

:::: warning Warning
As an admin, you **cannot unban** players. If an admin banned a player by mistake, the owner has to lift the ban.
::::

:::: info Note
Banned players currently do **not receive a notification** about the ban. They simply can no longer join your server and are not told why.
::::

:::: tip Revoke admin rights
Admin rights are not tied to individual players but apply to everyone who has entered the admin password – until it is changed. To revoke the rights of all current admins, change the [admin password](set-admin-password.md) in the dashboard and restart your server.
::::
