## Change the weather via the in-game chat

1. **Open the chat**\
   Open the chat. By default with the `t` key.

2. **Enter the command**\
   Enter one of the following commands to set the desired weather:

    ```text
    /weather clear    # Clears rain and fog!
    /weather thunder  # Starts a thunderstorm!
    /weather rain     # Starts rain!
    ```

## Change the weather via the server console

> [!WARNING]
> In the console, all commands must be entered without `/`!

1. **Select your server**\
   Open your dashboard and select your Minecraft Java Edition server.

2. **Open the console**\
   Navigate to the server console under the menu item "Overview".

3. **Enter the command**\
   Use one of the following weather commands in the console:

    ```text
    weather clear    # Clears rain and fog!
    weather thunder  # Starts a thunderstorm!
    weather rain     # Starts rain!
    ```
