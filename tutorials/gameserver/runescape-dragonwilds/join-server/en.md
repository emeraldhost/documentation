You can join your server in two ways: by searching for the **world name** on the Worlds screen or directly via the **Direct** tab using the **IP address** of your server.

> [!NOTE]
> You can find the world name in the **Settings** of your server in the dashboard. The IP address and the Game Port are shown in the dashboard under the **Overview**.

## Via world name

1. **Launch the game**\
   Start RuneScape: Dragonwilds.

2. **Open worlds**\
   Open the **Worlds** screen and select the **Public** tab.

3. **Search for server**\
   Open the **Search** and enter the exact world name of your server.

   > [!WARNING]
   > The world name is **case-sensitive**. It must match exactly.

4. **Join the server**\
   Wait a few seconds for your server to appear in the list and join.

## Via the Direct tab

1. **Launch the game**\
   Start RuneScape: Dragonwilds and open the **Worlds** screen.

2. **Open the Direct tab**\
   Select the **Direct** tab in the top bar.

3. **Enter connection details**\
   Enter the IP address and the Game Port of your server in the respective fields. If your server has a [server password](/tutorials/gameserver/runescape-dragonwilds/set-server-password), enter it in the field below.

   > [!TIP]
   > **Example**
   >
   > ```text
   > IP address: 123.45.67.89
   > Port: 7777
   > ```

4. **Select character and connect**\
   Select your character or create a new one and click **Play** to connect to the server.

> [!TIP]
> **Troubleshooting**
>
> If your server cannot be found via the world name:
>
> - Make sure the [Owner ID](/tutorials/gameserver/runescape-dragonwilds/set-owner-id) is set
> - Make sure the world name matches exactly
> - Check that your game and the server are on the same version
> - Wait a few minutes after starting the server before searching
> - Alternatively, connect via the **Direct** tab using the IP address
