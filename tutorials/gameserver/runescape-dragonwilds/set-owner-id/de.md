Die Owner ID ist Deine Epic Games ID und wird benötigt, damit Dein Server starten kann.

> [!TIP]
> Hier findest Du eine Anleitung, wie Du Deine [Epic Games ID](/tutorials/gameserver/epicgamesid-find-out) herausfindest. Du kannst Deine ID auch direkt im Spiel unter **Einstellungen** ganz unten bei **My Player ID** finden.

## Owner ID eintragen

1. **Verwaltung öffnen**\
   Öffne die Verwaltung Deines Servers.

2. **Einstellungen öffnen**\
   Navigiere zu den **Einstellungen**.

3. **Owner ID eintragen**\
   Trage Deine Player ID im Feld **Owner ID** ein.

4. **Server starten**\
   Speichere die Einstellung und starte Deinen Server.

> [!IMPORTANT]
> Der Server wird **nicht starten**, solange keine Owner ID eingetragen ist.
