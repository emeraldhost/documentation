Damit Dein Gameserver weiterläuft, verlängerst Du seine Laufzeit rechtzeitig. Das geht entweder manuell über den Button **Verlängern** oder automatisch, sodass Du nicht mehr an den Ablauf denken musst.

## Laufzeit prüfen

Öffne die Verwaltung Deines Servers. In der **Übersicht** siehst Du bei „Läuft ab in X Tagen“, wie lange Dein Server noch läuft, z.B. „Läuft ab in 4 Tagen“.

## Verfügbare Laufzeiten

Ab 90 Tagen erhältst Du einen Rabatt, der mit der Laufzeit steigt:

| Laufzeit | Rabatt |
| -------- | ------ |
| 10 Tage | – |
| 30 Tage | – |
| 90 Tage | 5 % |
| 180 Tage | 10 % |
| 365 Tage | 15 % |
| 730 Tage | 20 % |

## Server manuell verlängern

1. **Verlängerung öffnen**\
   Öffne die Verwaltung Deines Servers und klicke oben auf **Verlängern**. Es öffnet sich der Dialog **Server verlängern**.

2. **Laufzeit wählen**\
   Wähle im Schritt **Laufzeit** die gewünschte Verlängerungsdauer. Vorausgewählt sind **30 Tage**. Unten siehst Du den **Gesamtbetrag** für die gewählte Laufzeit.

3. **Zahlungsmethode wählen**\
   Wähle im Schritt **Zahlungsmethode**, wie Du bezahlen möchtest.

4. **Übersicht prüfen**\
   Prüfe in der **Übersicht** Deine Auswahl und den **Gesamtbetrag** und schließe die Verlängerung ab.

> [!NOTE]
> Für einen Wechsel auf die Performance-Klasse braucht Dein Server noch mindestens 14 Tage Laufzeit. Ist die Restlaufzeit kürzer, verlängere Deinen Server zuerst. Mehr dazu unter [Performance-Klasse wechseln](/tutorials/gameserver/change-performance-class).

## Automatische Verlängerung einrichten

Mit der automatischen Verlängerung wird Dein Server kurz vor Ablauf automatisch verlängert. Dafür hinterlegst Du eine Zahlungsmethode, die sicher bei unserem Zahlungsdienstleister gespeichert und kurz vor Ablauf belastet wird.

1. **Automatische Verlängerung öffnen**\
   Öffne die **Übersicht** Deines Servers. Solange Dein Server nicht automatisch verlängert wird, steht in der Box **Automatische Verlängerung** „Dein Server wird nicht automatisch verlängert“ mit dem Status **Inaktiv**. Öffne über diese Box den Dialog **Automatische Verlängerung**.

2. **Zahlungsmethode wählen**\
   Wähle im Schritt **Zahlungsmethode**, womit Dein Server automatisch verlängert werden soll. Zur Auswahl stehen **PayPal**, **Kreditkarte**, **Pay by Bank** und **EPS**.

3. **Einrichtung starten**\
   Klicke auf **Weiter zur Einrichtung** und folge den Schritten bis zur **Übersicht**.

> [!NOTE]
> Je nach Zahlungsart wird ein Verifizierungsbetrag von bis zu 1,00 € abgebucht. Diesen Betrag schreiben wir Deinem Guthaben gut.
