Squad 44 bietet keinen direkten Verbindungsaufbau über die IP-Adresse – Du trittst Deinem Server immer über den **Custom Browser** im Spiel bei.

## Voraussetzung

Notiere Dir den **Servernamen** Deines Servers. Diesen kannst Du in der Verwaltung unter **Einstellungen** anpassen – siehe [Server Name ändern](/tutorials/gameserver/squad-44/change-server-name).

## Server beitreten

1. **Squad 44 starten**\
   Starte Squad 44.

2. **Server-Browser öffnen**\
   Wähle im Hauptmenü **Server Browser**.

3. **Custom Browser öffnen**\
   Wechsle in den Tab **Custom Browser**.

4. **Server suchen**\
   Gib den Namen Deines Servers in das Suchfeld ein.

5. **Server beitreten**\
   Wähle Deinen Server aus der Liste und klicke auf **Join Server**. Falls Dein Server passwortgeschützt ist, gibst Du das Passwort ein und bestätigst.

> [!TIP]
> Damit Dein Server in der Serverliste angezeigt wird, muss die Option **Serverliste** aktiviert sein. Siehe [Serverliste aktivieren](/tutorials/gameserver/squad-44/enable-server-list).
