Squad 44 does not offer a direct connection via IP address – you always join your server through the **Custom Browser** in-game.

## Prerequisite

Note down the **server name** of your server. You can change it via the dashboard under **Settings** – see [Change Server Name](/tutorials/gameserver/squad-44/change-server-name).

## Join the server

1. **Start Squad 44**\
   Launch Squad 44.

2. **Open server browser**\
   Select **Server Browser** in the main menu.

3. **Open Custom Browser**\
   Switch to the **Custom Browser** tab.

4. **Search for server**\
   Enter your server's name in the search field.

5. **Join the server**\
   Select your server from the list and click **Join Server**. If your server is password-protected, enter the password and confirm.

> [!TIP]
> For your server to appear in the server list, the **Server List** option must be enabled. See [Enable Server List](/tutorials/gameserver/squad-44/enable-server-list).
