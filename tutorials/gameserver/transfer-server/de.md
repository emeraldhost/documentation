Über **Server übertragen** verschiebst Du Deinen Server in ein anderes Team oder übergibst ihn an einen anderen Nutzer. Das ist z.B. praktisch, wenn ein Mitspieler den Server künftig selbst verwalten soll.

## Server übertragen öffnen

1. **Aktionen öffnen**\
   Öffne die Verwaltung Deines Servers und klicke auf das Dropdown **Aktionen**.

2. **Server übertragen wählen**\
   Wähle **Server übertragen**. Im Dialog stehen Dir zwei Tabs zur Verfügung: **Team wechseln** und **Nutzer übertragen**.

## In ein anderes Team verschieben

1. **Team wechseln öffnen**\
   Wähle im Dialog den Tab **Team wechseln**.

2. **Ziel-Team wählen**\
   Wähle eines Deiner Teams als neues Ziel.

3. **Server verschieben**\
   Klicke auf **Jetzt verschieben**. Die Verschiebung erfolgt sofort.

> [!NOTE]
> Besitzt Du keine weiteren Teams, erscheint der Hinweis „Du besitzt keine weiteren Teams, in die dieser Server verschoben werden könnte.“ In diesem Fall nutzt Du den Tab **Nutzer übertragen**.

## An einen anderen Nutzer übertragen

1. **Nutzer übertragen öffnen**\
   Wähle im Dialog den Tab **Nutzer übertragen**.

2. **Empfänger eintragen**\
   Trag im Feld **Empfänger** den Benutzernamen oder die E-Mail-Adresse des neuen Inhabers ein.

3. **Anfrage senden**\
   Klicke auf **Anfrage senden**. Der Empfänger erhält eine Anfrage und hat 7 Tage Zeit, diese anzunehmen.

> [!IMPORTANT]
> Prüfe den Empfänger genau, bevor Du die Anfrage sendest. Nimmt er sie an, gehört der Server anschließend ihm.

> [!TIP]
> Erstelle vor der Übertragung ein Backup, damit Du einen gesicherten Stand Deines Servers hast. Wie das geht, erfährst Du unter [Backup erstellen](/tutorials/gameserver/create-backup).

## Anzeigenamen ändern

Der Anzeigename ist der Name Deines Servers in der Verwaltung. Der Servername, den Spieler im Spiel sehen, ändert sich dadurch nicht.

1. **Anzeigename ändern wählen**\
   Öffne das Dropdown **Aktionen** und wähle **Anzeigename ändern**.

2. **Neuen Namen eintragen**\
   Trag im Feld **Anzeigename** den neuen Namen ein.

3. **Speichern**\
   Klicke auf **Speichern**.

> [!TIP]
> Möchtest Du die Adresse ändern, über die Spieler Deinen Server erreichen, hilft Dir die Anleitung [Subdomain ändern](/tutorials/gameserver/change-subdomain).
