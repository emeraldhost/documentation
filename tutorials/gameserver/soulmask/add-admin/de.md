Du kannst Dir und anderen Spielern Admin-Rechte im Spiel vergeben.

## Voraussetzung

Bevor Du Dich als Admin anmelden kannst, muss ein Admin Passwort auf Deinem Server eingerichtet sein. Folge dazu der Anleitung [Admin Passwort setzen](/tutorials/gameserver/soulmask/set-admin-password).

## Als Admin anmelden

1. **Server beitreten**\
   Tritt Deinem Server bei.

2. **Konsole öffnen**\
   Drücke `~`, um die Konsole zu öffnen.

3. **Admin-Login**\
   Gib folgenden Befehl ein:

   ```text
   gm key DeinAdminPasswort
   ```

> [!NOTE]
> Die Admin-Anmeldung gilt nur für die aktuelle Sitzung. Nach einem Neuverbinden musst Du den Befehl erneut eingeben.
