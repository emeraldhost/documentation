Du kannst die aktive Busflotte auf Deinem Server per Befehl ändern.

## So änderst Du die Flotte

Gib folgenden Befehl im Ingame-Chat ein:

```text
/fleet <flotte>
```

> [!TIP]
> Dieser Befehl erfordert Owner- oder Admin-Rechte.
