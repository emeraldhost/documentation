> [!NOTE]
> Die Direktverbindung über IP-Adresse und Port ist standardmäßig **deaktiviert**. Wie Du sie aktivierst, erfährst Du unter [Direktverbindung aktivieren](/tutorials/gameserver/windrose/enable-direct-connection).

## Über den Invite Code

Um Deinem Server beizutreten, benötigst Du den [Invite Code](/tutorials/gameserver/windrose/set-invite-code) und – falls gesetzt – das [Server Passwort](/tutorials/gameserver/windrose/set-server-password).

1. **Windrose starten**\
   Starte Windrose.

2. **Spielen auswählen**\
   Klicke im Hauptmenü auf **Spielen**.

3. **Mit Server verbinden**\
   Wähle die Option **Mit Server verbinden** aus.

4. **Einladungscode eingeben**\
   Gib den Invite Code Deines Servers ein und klicke auf **Suchen**.

5. **Server auswählen**\
   Der gefundene Server wird rechts angezeigt. Klicke auf den Eintrag, um Dich zu verbinden.

6. **Passwort eingeben**\
   Falls der Server ein Passwort hat, gib dieses ein, um beizutreten.

> [!NOTE]
> Deinen Invite Code findest Du in der Verwaltung unter **Einstellungen** oder in der Datei `/R5/ServerDescription.json`. Der Code unterscheidet zwischen Groß- und Kleinschreibung – achte beim Eingeben auf die korrekte Schreibweise.

## Über die Direktverbindung (IP-Adresse)

> [!NOTE]
> **Voraussetzung**
>
> Die [Direktverbindung muss aktiviert](/tutorials/gameserver/windrose/enable-direct-connection) sein.

1. **Windrose starten**\
   Starte Windrose.

2. **Spielen auswählen**\
   Klicke im Hauptmenü auf **Spielen**.

3. **Mit Server verbinden**\
   Wähle die Option **Mit Server verbinden** aus.

4. **IP-Adresse eingeben**\
   Trage die IP-Adresse und den Port Deines Servers im Format `IP:Port` ein und bestätige.

   > [!TIP]
   > **Beispiel**
   >
   > ```text
   > 123.45.67.89:7777
   > ```
