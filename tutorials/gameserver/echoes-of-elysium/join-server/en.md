There are two ways onto your server: through the in-game server browser or directly via the IP address. Both lead to the same place – the direct connection is the more reliable one.

## Find connection details

> [!IMPORTANT]
> To connect you need the **IP address** and the **Game Port** of your server. You can find both in the **dashboard** of your server.

> [!NOTE]
> For joining you only enter the **Game Port**. A **Query Port** is not requested in the game.

## Connect directly via IP

1. **Start Echoes of Elysium**\
   Launch the game and wait until the main menu has loaded.

2. **Open Join**\
   Select **Join** in the main menu.

3. **Choose the direct connection**\
   Click on **Join IP Address**.

4. **Enter the server address**\
   In the **Server Address** field, enter the IP address and the Game Port of your server, separated by a colon:

   ```text
   <IP address>:<Game Port>
   ```

   You can find the matching values in the **dashboard**.

5. **Connect**\
   Click on **Start Game**.

6. **Enter the password**\
   If a password is set for your server, you are asked for it now. Enter the server password and confirm with **Next**.

## Via the server browser

1. **Start Echoes of Elysium**\
   Launch the game and wait until the main menu has loaded.

2. **Open Join**\
   Select **Join** in the main menu. You now see the list of available servers.

3. **Search for your server**\
   Look for the name of your server in the list. This is the name you set in the **dashboard** under **Settings**.

4. **Join the server**\
   Select your server and click on **Start Game**.

5. **Enter the password**\
   If a password is set for your server, enter it and confirm with **Next**.

> [!WARNING]
> **Server is not listed**
>
> If your server does not show up in the server browser, use the direct connection via **Join IP Address**. That way you reach your server regardless of whether it appears in the public list.
>
> Also check in the **dashboard** whether your server is running and fully started. Right after a start or an update it can take a moment until the server becomes reachable.

> [!TIP]
> Choose a distinctive server name. A very generic name is hard to find again in the server browser.
