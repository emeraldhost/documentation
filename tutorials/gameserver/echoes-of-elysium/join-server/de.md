Du kannst Deinem Server auf zwei Wegen beitreten: über den Serverbrowser im Spiel oder direkt über die IP-Adresse. Beide Wege führen zum selben Ziel – die Direktverbindung ist der zuverlässigere Weg.

## Verbindungsdaten finden

> [!IMPORTANT]
> Für die Verbindung benötigst Du die **IP-Adresse** und den **Game Port** Deines Servers. Beides findest Du in der **Verwaltung** Deines Servers.

> [!NOTE]
> Für den Beitritt trägst Du ausschließlich den **Game Port** ein. Ein **Query Port** wird im Spiel nicht abgefragt.

## Direkt über die IP verbinden

1. **Echoes of Elysium starten**\
   Starte das Spiel und warte, bis das Hauptmenü geladen ist.

2. **Join öffnen**\
   Wähle im Hauptmenü **Join**.

3. **Direktverbindung wählen**\
   Klicke auf **Join IP Address**.

4. **Serveradresse eintragen**\
   Trage im Feld **Server Address** die IP-Adresse und den Game Port Deines Servers ein, getrennt durch einen Doppelpunkt:

   ```text
   <IP-Adresse>:<Game Port>
   ```

   Die passenden Werte findest Du in der **Verwaltung**.

5. **Verbinden**\
   Klicke auf **Start Game**.

6. **Passwort eingeben**\
   Ist für Deinen Server ein Passwort gesetzt, wirst Du jetzt danach gefragt. Gib das Serverpasswort ein und bestätige mit **Next**.

## Über den Serverbrowser

1. **Echoes of Elysium starten**\
   Starte das Spiel und warte, bis das Hauptmenü geladen ist.

2. **Join öffnen**\
   Wähle im Hauptmenü **Join**. Du siehst nun die Liste der verfügbaren Server.

3. **Server suchen**\
   Suche in der Liste nach dem Namen Deines Servers. Das ist der Name, den Du in der **Verwaltung** unter **Einstellungen** gesetzt hast.

4. **Server beitreten**\
   Wähle Deinen Server aus und klicke auf **Start Game**.

5. **Passwort eingeben**\
   Ist für Deinen Server ein Passwort gesetzt, gib es ein und bestätige mit **Next**.

> [!WARNING]
> **Server wird nicht gefunden**
>
> Taucht Dein Server im Serverbrowser nicht auf, nutze die Direktverbindung über **Join IP Address**. Darüber erreichst Du Deinen Server unabhängig davon, ob er in der öffentlichen Liste angezeigt wird.
>
> Prüfe außerdem in der **Verwaltung**, ob Dein Server läuft und vollständig gestartet ist. Direkt nach einem Start oder einem Update kann es einen Moment dauern, bis der Server erreichbar ist.

> [!TIP]
> Vergib einen eindeutigen Servernamen. Ein sehr allgemeiner Name ist im Serverbrowser nur schwer wiederzufinden.
