## Find connection details

> [!NOTE]
> You can find the IP address and port of your server in the **dashboard** of your server under the overview.

## Search by server name

1. **Start FiveM**\
   Launch FiveM.

2. **Open server browser**\
   Click on **Play** in the main menu.

3. **Search for server**\
   Use the filter and search for the name of your server in the server list.

4. **Join the server**\
   Select your server from the list and click **Connect**.

## Via Direct Connect

1. **Start FiveM**\
   Launch FiveM.

2. **Open console**\
   Press `F8` to open the console.

3. **Connect**\
   Enter the following command:

   ```text
   connect IP:Port
   ```

   > [!TIP]
   > **Example**
   >
   > ```text
   > connect 123.45.67.89:30120
   > ```
