Deinen No Love Lost Server findest Du im Spiel über die **Serverliste**. Dort erscheint er unter dem **Servernamen**, der in der **Verwaltung** hinterlegt ist. Damit er in der Liste auftaucht, müssen der **Game Port** und der **Query Port** Deines Servers erreichbar sein.

## Verbindungsdaten finden

> [!IMPORTANT]
> Den Servernamen sowie den Game Port und den Query Port Deines Servers findest Du in der **Verwaltung**. Notiere Dir vor allem den Servernamen – über ihn findest Du Deinen Server im Spiel wieder.

Beide Ports werden Dir beim Anlegen des Servers automatisch zugewiesen und unterscheiden sich immer voneinander:

| Port | Aufgabe |
|------|---------|
| **Game Port** | Über diesen Port läuft die eigentliche Verbindung zum Server. |
| **Query Port** | Über diesen Port beantwortet Dein Server Serverabfragen, damit er in der Liste im Spiel auftaucht. |

> [!NOTE]
> Du musst keine Ports von Hand freigeben. Beide Ports sind auf Deinem Server bereits eingerichtet und offen.

## Server beitreten

1. **Server starten**\
   Starte Deinen Server in der **Verwaltung** und warte, bis er vollständig hochgefahren ist. Erst danach ist er erreichbar.

2. **Servernamen prüfen**\
   Sieh in der Verwaltung nach, welcher **Servername** für Deinen Server hinterlegt ist. Genau unter diesem Namen erscheint er im Spiel.

3. **No Love Lost starten**\
   Starte No Love Lost über Steam auf Deinem PC.

4. **Serverliste öffnen**\
   Öffne im Spiel die Liste der verfügbaren Server.

5. **Nach Deinem Server suchen**\
   Suche in der Liste nach dem Namen Deines Servers.

6. **Server beitreten**\
   Wähle Deinen Server aus der Liste aus und tritt ihm bei.

> [!TIP]
> Wähle einen möglichst eindeutigen Servernamen. Ein sehr allgemeiner Name macht es unnötig schwer, Deinen Server in der Liste von den übrigen zu unterscheiden.

## Dein Server erscheint nicht in der Liste

> [!WARNING]
> Taucht Dein Server nicht in der Serverliste auf, arbeite diese Punkte der Reihe nach ab:
>
> - **Server wirklich online?** Prüfe in der Verwaltung, ob der Server läuft und nicht gerade neu startet oder ein Update installiert.
> - **Nach dem Start etwas Zeit geben.** Direkt nach dem Start dauert es einen Moment, bis der Server in der Liste auftaucht.
> - **Schreibweise des Namens prüfen.** Suche exakt nach dem Namen aus der Verwaltung, am besten nur nach einem eindeutigen Teil davon.
> - **Liste aktualisieren.** Verlasse die Serverliste im Spiel und öffne sie erneut, damit die Liste neu abgefragt wird.
> - **Servername geändert?** Der Servername wird beim Start des Servers übergeben. Nach einer Änderung musst Du den Server neu starten, damit der neue Name übernommen wird.
