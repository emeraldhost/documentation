1. **Launch Renown**\
   Start Renown.

2. **Select Play**\
   Click **Play** in the main menu.

3. **Select region**\
   Choose your region.

4. **Show all**\
   Click **All** to show all available servers.

5. **Search for server**\
   Search for your server's name in the search field.

6. **Join the server**\
   Select your server from the list and click **Join**. If your server is password-protected, enter the password and confirm.

> [!TIP]
> For your server to appear in the public server list, [Public Server](/tutorials/gameserver/renown/change-public-server) must be set to `True` and [Private Session](/tutorials/gameserver/renown/change-private-session) must be set to `False`.
