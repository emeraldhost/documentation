1. **Renown starten**\
   Starte Renown.

2. **Spielen auswählen**\
   Klicke im Hauptmenü auf **Spielen**.

3. **Region auswählen**\
   Wähle Deine Region aus.

4. **Alle anzeigen**\
   Klicke auf **Alle**, um alle verfügbaren Server anzuzeigen.

5. **Server suchen**\
   Suche nach dem Namen Deines Servers im Suchfeld.

6. **Server beitreten**\
   Wähle Deinen Server aus der Liste und klicke auf **Beitreten**. Falls Dein Server passwortgeschützt ist, gib das Passwort ein und bestätige.

> [!TIP]
> Damit Dein Server in der öffentlichen Serverliste angezeigt wird, muss [Öffentlicher Server](/tutorials/gameserver/renown/change-public-server) auf `True` und [Private Sitzung](/tutorials/gameserver/renown/change-private-session) auf `False` gesetzt sein.
