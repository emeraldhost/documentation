Wenn aktiviert, lädt Dein Server beim Start immer die erste Map aus der [Map Rotation](/tutorials/gameserver/renown/change-map-rotation), anstatt sie zufällig oder anhand des letzten Spielzustands zu wählen.

1. **Verwaltung öffnen**\
   Öffne die Verwaltung Deines Servers.

2. **Einstellungen öffnen**\
   Navigiere zu den **Einstellungen**.

3. **Use First Map anpassen**\
   Setze das Feld **Use First Map** auf den gewünschten Wert:
   - `True` – Use First Map ist aktiviert
   - `False` – Use First Map ist deaktiviert

4. **Server neu starten**\
   Speichere die Einstellung und starte Deinen Server neu.
