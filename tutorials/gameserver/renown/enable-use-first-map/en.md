When enabled, your server always loads the first map from the [Map Rotation](/tutorials/gameserver/renown/change-map-rotation) on startup, instead of selecting one randomly or based on the last game state.

1. **Open dashboard**\
   Open the dashboard of your server.

2. **Open settings**\
   Navigate to the **Settings**.

3. **Adjust Use First Map**\
   Set the **Use First Map** field to the desired value:
   - `True` – use first map is enabled
   - `False` – use first map is disabled

4. **Restart the server**\
   Save the setting and restart your server.
