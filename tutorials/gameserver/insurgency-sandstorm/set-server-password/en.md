You can protect your server with a password so that only players with the password can join. This is especially useful when your server appears in the server list via the [server tokens](/tutorials/gameserver/insurgency-sandstorm/set-game-stats-token) but you still don't want random players to join.

1. **Open dashboard**\
   Open the dashboard of your server.

2. **Open settings**\
   Navigate to the **Settings**.

3. **Set password**\
   Enter the desired password in the **Server Password** field and save the setting.

4. **Restart the server**\
   Restart your server for the change to take effect.

> [!TIP]
> To remove the password and make your server public again, clear the password field and save.
