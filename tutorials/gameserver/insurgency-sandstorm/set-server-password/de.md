Du kannst Deinen Server mit einem Passwort schützen, sodass nur Spieler mit dem Passwort beitreten können. Das ist besonders sinnvoll, wenn Dein Server über die [Server Tokens](/tutorials/gameserver/insurgency-sandstorm/set-game-stats-token) in der Serverliste auftaucht und Du trotzdem nicht möchtest, dass beliebige Spieler beitreten.

1. **Verwaltung öffnen**\
   Öffne die Verwaltung Deines Servers.

2. **Einstellungen öffnen**\
   Navigiere zu den **Einstellungen**.

3. **Passwort setzen**\
   Trage im Feld **Server Passwort** das gewünschte Passwort ein und speichere die Einstellung.

4. **Server neu starten**\
   Starte Deinen Server neu, damit die Änderung übernommen wird.

> [!TIP]
> Um das Passwort zu entfernen und den Server wieder öffentlich zu machen, lösche den Eintrag im Passwort-Feld und speichere.
