As an admin you can kick or permanently ban disruptive or rule-breaking players directly in-game via the admin menu.

## Requirement

You need admin rights on the server. To learn how to add yourself as an admin, see [Add Admins](/tutorials/gameserver/insurgency-sandstorm/add-admins).

## Kick or ban a player

1. **Join the server**\
   Join your server.

2. **Open the admin menu**\
   Open the admin menu with the assigned key – by default the **Minus** key (`-`) on the numpad.

3. **Open the player list**\
   Switch to the **Players** tab.

4. **Select a player**\
   Select the desired player and click **Kick** or **Ban**.

> [!TIP]
> For self-moderation without fixed admins, you can additionally enable [player voting](/tutorials/gameserver/insurgency-sandstorm/configure-player-voting), which lets players remove problematic players by vote.
