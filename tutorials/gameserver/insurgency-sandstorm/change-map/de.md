Die Map legt fest, welche Karte beim Start des Servers geladen wird (z.B. `Ministry`, `Refinery`, `Hideout`).

1. **Verwaltung öffnen**\
   Öffne die Verwaltung Deines Servers.

2. **Einstellungen öffnen**\
   Navigiere zu den **Einstellungen**.

3. **Map ändern**\
   Trage im Feld **Map** den Namen der gewünschten Karte ein und speichere die Einstellung.

4. **Server neu starten**\
   Starte Deinen Server neu, damit die Änderung übernommen wird.

> [!NOTE]
> Die Map muss zum gewählten [Szenario](/tutorials/gameserver/insurgency-sandstorm/change-scenario) passen. Eine vollständige Liste der Karten und Szenarien findest Du im offiziellen [Server Admin Guide](https://mod.io/g/insurgencysandstorm/r/server-admin-guide).
