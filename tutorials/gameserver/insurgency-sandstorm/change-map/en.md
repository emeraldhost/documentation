The map determines which map is loaded when the server starts (e.g. `Ministry`, `Refinery`, `Hideout`).

1. **Open dashboard**\
   Open the dashboard of your server.

2. **Open settings**\
   Navigate to the **Settings**.

3. **Change the map**\
   Enter the name of the desired map in the **Map** field and save the setting.

4. **Restart the server**\
   Restart your server for the change to take effect.

> [!NOTE]
> The map must match the selected [scenario](/tutorials/gameserver/insurgency-sandstorm/change-scenario). A full list of maps and scenarios can be found in the official [Server Admin Guide](https://mod.io/g/insurgencysandstorm/r/server-admin-guide).
