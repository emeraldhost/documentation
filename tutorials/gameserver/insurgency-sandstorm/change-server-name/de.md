Du kannst den Anzeigenamen Deines Servers ändern, der in der Serverliste angezeigt wird.

1. **Verwaltung öffnen**\
   Öffne die Verwaltung Deines Servers.

2. **Einstellungen öffnen**\
   Navigiere zu den **Einstellungen**.

3. **Server Name ändern**\
   Trage den gewünschten Namen im Feld **Server Name** ein und speichere die Einstellung.

4. **Server neu starten**\
   Starte Deinen Server neu, damit die Änderung übernommen wird.

> [!NOTE]
> Damit Dein Server überhaupt in der Serverliste erscheint, müssen zusätzlich [Game Stats Token](/tutorials/gameserver/insurgency-sandstorm/set-game-stats-token) und [GSL Token](/tutorials/gameserver/insurgency-sandstorm/set-gsl-token) hinterlegt sein.
