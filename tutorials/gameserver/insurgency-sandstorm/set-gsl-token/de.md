Der GSL Token (Game Server Login Token) wird benötigt, damit Dein Server in der Serverliste angezeigt wird.

## Token generieren

1. **Steam Game Server Seite öffnen**\
   Öffne [https://steamcommunity.com/dev/managegameservers\x{FDD0}0\x{FDD1} und melde Dich mit Deinem Steam-Konto an.

2. **Token erstellen**\
   Erstelle einen neuen Token mit der App-ID **581320** (Insurgency: Sandstorm) und kopiere ihn.

## Token hinterlegen

1. **Verwaltung öffnen**\
   Öffne die Verwaltung Deines Servers.

2. **Einstellungen öffnen**\
   Navigiere zu den **Einstellungen**.

3. **Token eintragen**\
   Füge den Token im Feld **GSL Token** ein und speichere die Einstellung.

4. **Server neu starten**\
   Starte Deinen Server neu, damit die Änderung übernommen wird.

> [!NOTE]
> Zusätzlich wird ein [Game Stats Token](/tutorials/gameserver/insurgency-sandstorm/set-game-stats-token) benötigt, damit Dein Server in der Serverliste erscheint.
