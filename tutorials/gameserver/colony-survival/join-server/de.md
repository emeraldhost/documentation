Du verbindest Dich mit Deinem Colony Survival Server **nicht über IP-Adresse und Port**, sondern über den Serverbrowser im Spiel: Dort suchst Du nach dem **Namen Deines Servers** und trittst ihm per Klick bei.

> [!IMPORTANT]
> Das Wichtigste für den Beitritt ist ein **eindeutiger Servername**. Welchen Namen Dein Server trägt, siehst Du in der **Verwaltung**. Heißt Dein Server wie hunderte andere, findest Du ihn in der Liste kaum wieder.

## Server im Spiel beitreten

1. **Colony Survival starten**\
   Starte das Spiel und warte, bis das Hauptmenü geladen ist.

2. **Multiplayer öffnen**\
   Wähle im Hauptmenü **Multiplayer**.

3. **Passende Liste wählen**\
   Oben findest Du mehrere Reiter:

   | Reiter | Inhalt |
   |--------|--------|
   | **Internet** | Alle öffentlich gelisteten Server – hier findest Du Deinen eigenen Server |
   | **Friends** | Server von Spielern auf Deiner Steam-Freundesliste |
   | **LAN** | Server im selben lokalen Netzwerk |
   | **History** | Server, denen Du zuletzt beigetreten bist |

4. **Server suchen**\
   Suche in der Liste nach dem Namen Deines Servers. Mit den Filtern über der Liste – etwa **Show Empty** oder **Show Full** – grenzt Du die Auswahl ein.

5. **Beitreten**\
   Wähle Deinen Server aus und klicke auf **Join**.

6. **Passwort eingeben**\
   Ist für Deinen Server ein Passwort gesetzt, wirst Du jetzt danach gefragt.

> [!TIP]
> Nach dem ersten Beitritt findest Du Deinen Server über den Reiter **History** wieder, ohne jedes Mal die komplette Serverliste durchsuchen zu müssen.

## Warum brauchst Du keinen Port?

> [!NOTE]
> Dein Server nutzt die Steam-Netzwerkanbindung: Er meldet sich damit beim Serverbrowser an, und auch der Verbindungsaufbau läuft anschließend über Steam. Deshalb gibst Du im Spiel weder eine IP-Adresse noch einen Port ein.
>
> **Game Port** und **Query Port** Deines Servers siehst Du in der **Verwaltung**. Für den normalen Beitritt brauchst Du sie nicht – sie werden im Hintergrund verwendet.

> [!WARNING]
> Ältere Anleitungen richten sich meist an selbst gehostete Server und erklären dort Portfreigaben im Router. Auf Deinem gemieteten Server ist das nicht nötig – die Ports sind bereits eingerichtet und stehen in der **Verwaltung**.

## Server wird nicht angezeigt

Taucht Dein Server nicht in der Liste auf, arbeite die folgenden Punkte ab:

1. **Läuft der Server?**\
   Prüfe in der **Verwaltung**, ob Dein Server gestartet ist und keine Fehler in der Konsole stehen.

2. **Liste aktualisieren**\
   Verlasse das Multiplayer-Menü und öffne es erneut. Nach einem Serverstart dauert es einen Moment, bis der Server in der öffentlichen Liste erscheint.

3. **Nach dem exakten Namen suchen**\
   Suche nach einem eindeutigen Teil Deines Servernamens. Die Liste ist lang – ohne Suche findest Du Deinen Server nur schwer.

4. **Über Freunde beitreten**\
   Ist bereits jemand von Deiner Steam-Freundesliste auf dem Server, findest Du ihn auch über den Reiter **Friends**.

> [!NOTE]
> Bekommst Du beim Verbinden die Meldung, dass Du auf der Blacklist stehst oder nicht auf der Whitelist bist, wurdest Du vom Server ausgeschlossen. Wie Du diese Listen verwaltest, steht unter [Spieler kicken & bannen](/tutorials/gameserver/colony-survival/kick-ban-players).
