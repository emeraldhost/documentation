1. **Open dashboard**\
   Open the dashboard of your server.

2. **Open settings**\
   Navigate to the **Settings**.

3. **Enter world mode**\
   Enter the desired value in the **World Mode** field:

   | Value | Description |
   |-------|-------------|
   | `0` | Normal mode |
   | `1` | Hard mode |

4. **Restart the server**\
   Save the setting and restart your server.
