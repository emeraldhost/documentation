You can join your Core Keeper server in two ways: directly via the **IP address and Game Port** or via the **Game ID**. We recommend connecting via IP and port — in our experience, the Game ID frequently causes connection problems.

## Find connection details

> [!NOTE]
> You can find the IP address and the Game Port of your server in the **dashboard** of your server under the overview. The Game ID is printed in the server console at startup.

## Via IP and port (recommended)

1. **Start Core Keeper**\
   Launch Core Keeper.

2. **Open Join Game**\
   Click on **Co-op** and select **Join Game**.

3. **Select character**\
   Select your character.

4. **Switch to IP connection**\
   Click the arrow next to **Join with Game ID** and select **Join with IP**.

5. **Enter connection details**\
   Enter the IP address and the Game Port of your server in the respective fields. If your server has a password, enter it in the field below.

   > [!TIP]
   > **Example**
   >
   > ```text
   > IP address: 123.45.67.89
   > Port: 27015
   > ```

6. **Connect**\
   Click **Join** to connect to the server.

## Via Game ID

> [!WARNING]
> Connecting via the Game ID goes through the Steam relay network and fails more often. Only use this method if connecting via IP and port is not possible.

1. **Start Core Keeper**\
   Launch Core Keeper.

2. **Open Join Game**\
   Click on **Co-op** and select **Join Game**.

3. **Select character**\
   Select your character.

4. **Enter Game ID**\
   Enter the **Game ID** of your server in the input field.

5. **Connect**\
   Click **Join** to connect to the server.
