Du kannst Deinem Core Keeper Server auf zwei Wegen beitreten: direkt über die **IP-Adresse und den Game Port** oder über die **Game ID**. Wir empfehlen die Verbindung über IP und Port — die Game ID führt erfahrungsgemäß häufig zu Verbindungsproblemen.

## Verbindungsdaten finden

> [!NOTE]
> Die IP-Adresse und den Game Port Deines Servers findest Du in der **Verwaltung** Deines Servers unter der Übersicht. Die Game ID wird beim Start in der Server-Konsole ausgegeben.

## Über IP und Port (empfohlen)

1. **Core Keeper starten**\
   Starte Core Keeper.

2. **Join Game öffnen**\
   Klicke auf **Co-op** und wähle **Join Game**.

3. **Charakter auswählen**\
   Wähle Deinen Charakter aus.

4. **Auf IP-Verbindung umschalten**\
   Klicke neben **Join with Game ID** auf den Pfeil und wähle **Join with IP**.

5. **Verbindungsdaten eingeben**\
   Trage die IP-Adresse und den Game Port Deines Servers in die jeweiligen Felder ein. Hat Dein Server ein Passwort, gib es im Feld darunter an.

   > [!TIP]
   > **Beispiel**
   >
   > ```text
   > IP-Adresse: 123.45.67.89
   > Port: 27015
   > ```

6. **Verbinden**\
   Klicke auf **Join**, um dem Server beizutreten.

## Über die Game ID

> [!WARNING]
> Die Verbindung über die Game ID läuft über das Steam-Relay-Netzwerk und schlägt häufiger fehl. Nutze diesen Weg nur, wenn die Verbindung über IP und Port nicht möglich ist.

1. **Core Keeper starten**\
   Starte Core Keeper.

2. **Join Game öffnen**\
   Klicke auf **Co-op** und wähle **Join Game**.

3. **Charakter auswählen**\
   Wähle Deinen Charakter aus.

4. **Game ID eingeben**\
   Gib die **Game ID** Deines Servers in das Eingabefeld ein.

5. **Verbinden**\
   Klicke auf **Join**, um dem Server beizutreten.
