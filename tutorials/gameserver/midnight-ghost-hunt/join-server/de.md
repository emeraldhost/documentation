Deinen Midnight Ghost Hunt Server findest Du im Spiel über die **Serverliste**. Dort erscheint er unter dem **Servernamen**, der für ihn hinterlegt ist – und zwar in der **Region**, die für Deinen Server eingestellt ist. Beides wird beim Start des Servers übergeben, Du solltest Dir also vorher beides notieren.

## Verbindungsdaten finden

> [!IMPORTANT]
> Den Servernamen, die Region und ein eventuell gesetztes Serverpasswort findest Du in der **Verwaltung** Deines Servers. Vor allem der Servername und die Region sind entscheidend – über sie findest Du Deinen Server in der Liste wieder.

Ein Midnight Ghost Hunt Server belegt mehrere Ports, die Dir beim Anlegen des Servers automatisch zugewiesen werden:

| Port | Aufgabe |
|------|---------|
| **Game Port** | Über diesen Port läuft die eigentliche Verbindung zum Server. |
| **Query Port** | Über diesen Port beantwortet Dein Server Serverabfragen, damit er in der Liste im Spiel auftaucht. |
| **Beacon Port** | Zusätzlicher Port, über den Dein Server die Menü- und Beitrittsinformationen an die Spieler ausliefert. |

> [!NOTE]
> Du musst keine Ports von Hand freigeben. Alle Ports sind auf Deinem Server bereits eingerichtet und offen. Welche Werte für Deinen Server gelten, siehst Du in der **Verwaltung**.

## Server beitreten

1. **Server starten**\
   Starte Deinen Server in der **Verwaltung** und warte, bis er vollständig hochgefahren ist. Erst danach ist er erreichbar und taucht in der Serverliste auf.

2. **Servername und Region prüfen**\
   Sieh in der Verwaltung nach, welcher **Servername** und welche **Region** für Deinen Server hinterlegt sind. Genau unter diesem Namen und in dieser Region erscheint er im Spiel.

3. **Midnight Ghost Hunt starten**\
   Starte Midnight Ghost Hunt über Steam auf Deinem PC.

4. **Serverliste öffnen**\
   Öffne im Spiel die Liste der verfügbaren Server.

5. **Nach Deinem Server suchen**\
   Suche in der Liste nach dem Namen Deines Servers. Achte darauf, dass Du in der Region suchst, die für Deinen Server eingestellt ist.

6. **Passwort eingeben**\
   Ist für Deinen Server ein Passwort gesetzt, wirst Du beim Beitreten danach gefragt. Gib das Passwort aus der Verwaltung ein.

7. **Server beitreten**\
   Wähle Deinen Server aus der Liste aus und tritt ihm bei. Du landest anschließend in der laufenden beziehungsweise nächsten Runde.

> [!TIP]
> Wähle einen möglichst eindeutigen Servernamen. Ein sehr allgemeiner Name macht es unnötig schwer, Deinen Server in der Liste von den übrigen zu unterscheiden. Der Name muss außerdem länger als drei Zeichen sein.

## Region Deines Servers

Die Region entscheidet, unter welchem Gebiet Dein Server in der Serverliste einsortiert wird. Wähle sie passend zum Standort Deines Servers beziehungsweise zu dem Ort, an dem Deine Mitspieler sitzen. Folgende Regionen stehen zur Auswahl:

- North America
- South America
- Western Europe
- Northern Europe
- Eastern Europe
- Middle East
- Asia
- Africa
- Oceania

> [!NOTE]
> Suchst Du in einer anderen Region, als für Deinen Server eingestellt ist, findest Du ihn nicht. Sag Deinen Mitspielern also am besten direkt, in welcher Region sie suchen müssen.

## Passwortgeschützter Server

Ist für Deinen Server ein Passwort hinterlegt, benötigen alle Mitspieler dieses Passwort, um beitreten zu können. Gib es deshalb nur an die Personen weiter, die auf Deinem Server spielen sollen.

> [!WARNING]
> Änderungen am Passwort werden erst beim nächsten Start des Servers übernommen. Starte Deinen Server nach einer Änderung über die **Verwaltung** neu.

## Dein Server erscheint nicht in der Liste

> [!WARNING]
> Taucht Dein Server nicht in der Serverliste auf, arbeite diese Punkte der Reihe nach ab:
>
> - **Server wirklich online?** Prüfe in der Verwaltung, ob der Server läuft und nicht gerade neu startet oder ein Update installiert.
> - **Nach dem Start etwas Zeit geben.** Direkt nach dem Start dauert es einen Moment, bis der Server in der Liste auftaucht.
> - **Richtige Region gewählt?** Dein Server erscheint ausschließlich in der Region, die für ihn eingestellt ist.
> - **Schreibweise des Namens prüfen.** Suche exakt nach dem Namen aus der Verwaltung, am besten nur nach einem eindeutigen Teil davon.
> - **Ist der Name lang genug?** Ein Servername muss länger als drei Zeichen sein, sonst wird der Server nicht korrekt gelistet.
> - **Liste aktualisieren.** Verlasse die Serverliste im Spiel und öffne sie erneut, damit die Liste neu abgefragt wird.
> - **Etwas geändert?** Servername, Region und Passwort werden beim Start des Servers übergeben. Nach einer Änderung musst Du den Server neu starten, damit die neuen Werte übernommen werden.
