## Find connection details

> [!NOTE]
> You can find the IP address and port of your server in the **dashboard** of your server under the overview. The default port is `26900`.

## Via Steam server browser

1. **Open Steam**\
   Open the Steam client.

2. **Open server browser**\
   Click on **View** in the top left and select **Game Servers**.

3. **Add server**\
   Click on the **Favorites** tab and then on **+** at the bottom right.

4. **Enter server address**\
   Enter the IP address and port of your server.

   > [!TIP]
   > **Example**
   >
   > ```text
   > 123.45.67.89:26900
   > ```

5. **Connect**\
   Select the server and click **Connect**.

## Search by server name

1. **Launch the game**\
   Start 7 Days to Die.

2. **Join a Game**\
   Click on **Join a Game**.

3. **Search for server**\
   Use the filter and search for the name of your server in the server list.

4. **Join the server**\
   Select your server from the list and click **Connect**.

## Via Direct Connect

1. **Launch the game**\
   Launch 7 Days to Die.

2. **Join a Game**\
   Click on **Join a Game**.

3. **Connect to IP**\
   Click on **Connect to IP** and enter the IP address and port of your server.

   > [!TIP]
   > **Example**
   >
   > ```text
   > 123.45.67.89:26900
   > ```

4. **Connect**\
   Click **Connect**.
