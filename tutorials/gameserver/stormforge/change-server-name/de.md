Den Namen Deines Servers legst Du im **Config-Editor** fest. Auf einem neuen Server lautet er `Stormforge Server by emeraldhost.de`.

1. **Verwaltung öffnen**\
   Öffne die **Verwaltung** Deines Servers.

2. **Config-Editor öffnen**\
   Navigiere zum **Config-Editor**.

3. **Server Name ändern**\
   Trage den gewünschten Namen im Feld **Server Name** ein und speichere die Einstellung. Der Name darf höchstens 64 Zeichen lang sein, und das Feld darf nicht leer bleiben.

4. **Server neu starten**\
   Starte Deinen Server neu, damit die Änderung übernommen wird.

> [!NOTE]
> Ändere den Namen immer im **Config-Editor**. Bei jedem Start wird der Wert aus dem Feld **Server Name** als `serverName` in die Datei `settings.json` geschrieben. Eine Änderung von Hand in der Datei wird dabei überschrieben.
