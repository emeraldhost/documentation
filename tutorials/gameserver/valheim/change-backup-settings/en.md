You can configure how often and how many backups the server creates.

1. **Open dashboard**\
   Open the dashboard of your server.

2. **Open settings**\
   Navigate to the **Settings**.

3. **Adjust backup settings**\
   Adjust the following fields:

   | Field | Description |
   |-------|-------------|
   | **Backup Interval** | Time in seconds between backups |
   | **Backup Count** | Number of backups to keep |
   | **Backup Shorttime** | Interval for short-term backups (in seconds) |
   | **Backup Longtime** | Interval for long-term backups (in seconds) |

4. **Restart the server**\
   Save the settings and restart your server.
