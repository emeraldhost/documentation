You can configure whether your server is shown in the public server list.

1. **Open dashboard**\
   Open the dashboard of your server.

2. **Open settings**\
   Navigate to the **Settings**.

3. **Configure server list**\
   Enter the desired value in the **Server List** field:

   | Value | Description |
   |-------|-------------|
   | `1` | Server is shown in the public server list |
   | `0` | Server is not shown in the server list |

4. **Restart the server**\
   Save the setting and restart your server.
